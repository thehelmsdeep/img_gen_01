# Installation

This document will contain the reproducible setup procedure as the implementation is added.

## Planned requirements

- Python
- A supported ML framework
- Image-processing dependencies
- Optional GPU runtime
- Downloaded model weights

## General workflow

~~~text
1. Clone the repository
2. Create a virtual environment
3. Install Python dependencies
4. Download a compatible model
5. Configure the model path
6. Run the local generator
7. Inspect the generated image
~~~

Exact commands will be added when the first executable implementation is committed.

## Hardware note

The project is intended to support systems with limited hardware where possible. Model selection, image resolution, batch size, precision, and memory-management techniques can have a major effect on requirements.
